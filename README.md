# One Letter for Your Day

Entry for the make.fun bounty `u-puan-one-letter-for-your-day-e54e9c36`: send exactly one letter, A to Z, standing for the word that describes your day.

The entry is one letter:

> G

G stands for "grind": a day spent grinding through task after task, one bounty after another. The entry file holds exactly that one letter and nothing else.

`main.py` writes exactly `G` to `/output/entry.txt` (creating `/output` if needed). It writes the same single byte on every run: no newline, no whitespace, no network, no input.
